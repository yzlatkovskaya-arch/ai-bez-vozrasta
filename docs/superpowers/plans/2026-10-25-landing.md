# Лендинг «Нейросети без возраста» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Один файл `index.html`: лендинг бесплатного вебинара по ИИ для работающих 45+, читается за 10 секунд, хорошо выглядит на телефоне.

**Architecture:** Статичная страница из четырёх `<section>` в одном файле, стили в `<style>` через CSS-переменные, JS только для заглушки формы. Задачи наполняют файл по частям и не трогают чужие секции.

**Tech Stack:** HTML5, CSS3 (системные шрифты), немного ванильного JS. Проверка: `grep` и Playwright MCP.

**Spec:** `docs/superpowers/specs/2026-10-25-landing-design.md` (читать целиком перед задачей).

## Global Constraints

- Файл: `C:\Users\Юля\Work\StartUp\landing\index.html`, стили внутри `<style>`.
- Нет внешних библиотек, шрифтов, картинок, скриптов, счётчиков: ни одного `http://`, `https://`, `//cdn`, `@import url`, `<link rel="stylesheet">`.
- Шрифт: системный стек `-apple-system, "Segoe UI", Roboto, Arial, sans-serif`; основной текст не меньше 18px.
- Язык `<html lang="ru">`, обращение на «вы», тон тёплый и спокойный, без жаргона («промпт», «LLM», «модель») и без слов «пенсионеры», «даже вы сможете».
- Светлая тема, тёплый фон, контраст текста не ниже WCAG AA, одна акцентная кнопка.
- Ширина от 360px без горизонтальной прокрутки; кнопка и поля не ниже 48px по высоте.
- Единственное главное действие: «Записаться на бесплатный вебинар». Даты вебинара на странице нет («Дату сообщим после записи»).
- Юлия разрешила локальные коммиты в ветке feature/landing: исполнитель коммитит в конце задачи. Push запрещён.

## Review Focus

- Пустые поля формы: отправка блокируется, показывается мягкое сообщение, страница не перезагружается.
- Поле контакта принимает любой непустой текст; пробелы вместо текста считаются пустыми.
- Повторное нажатие кнопки после успеха не создаёт второго «Спасибо».
- Очень узкий экран 320px: заголовок не обрезается, нет горизонтальной прокрутки.
- Увеличенный шрифт в браузере (200%): текст не налезает на кнопки.
